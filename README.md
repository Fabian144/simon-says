# Simon says - A sequence memory game 🔴🟢🔵🟡

Simon says is a memory game where the goal is to memorize and mimic a sequence of LED flashes. The sequence gets longer each round, choose the wrong color once and you lose!

## Features 🔍

- **4 LED lights** that light up randomly, one per round.
- **A buzzer** that plays a specific tone for each LED when it lights up.
- **4 buttons** that match the colors of the LEDs, used by the player to mimic the sequence.
- **A speaker** with audio stored on an SD card. It plays a random success or fail sound after each round depending on the outcome. A voice makes fun of the player with different random phrases when the player loses.
- **An LCD display** that displays the score, as well as "GAME OVER" if the player loses.

## Tools 🛠️
This project was built using:
- **ESP32**
- **Arduino C++**
